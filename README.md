# MaCoKi Patient Management System (APMS)

A clean, mobile-friendly React + TypeScript + Vite clinic management starter.

## Included modules
- Dashboard
- Patient registration and search
- Clinical visits
- Follow-ups
- Pharmacy inventory with batch/expiry/reorder status
- Laboratory requests
- ANC / Maternity records
- Reports
- Settings and role selector
- Dark mode
- LocalStorage persistence
- PWA manifest and service worker

## Run
```bash
npm install
npm run dev
```

Open the forwarded port **5173** in Codespaces.

## Production note
This is a functional frontend/local-first prototype. It is not a production clinical information system. Real deployment requires a secure backend, authentication, authorization enforcement, encryption, audit logs, backups, privacy controls, validation, and appropriate regulatory/security review.
